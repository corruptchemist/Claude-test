Continuity at a given x-value · #1–6

Every one of these follows the same three-part test: is f(c) defined, do the left and right sides approach the same height, and do those two match?

1f(x) = x³ − 4x² + 3at x = 4

Type: polynomial

  1. Identify the function type. No denominator, no radical, no pieces — it's a polynomial.
  2. Find f(4). f(4) = (4)³ − 4(4)² + 3 = 64 − 4(16) + 3 = 64 − 64 + 3 = 3. It's defined. ✓
  3. Find the limit. Polynomials allow direct substitution, so limx→4 f(x) = 3 from both sides. ✓
  4. Compare. limx→4 f(x) = 3 = f(4). All three conditions pass.

AnswerContinuous at x = 4 (polynomials are continuous everywhere).

2f(x) = x² + 8x + 15 if x < −2; −2x − 10 if x ≥ −2, at x = −2

Type: piecewise — test the split point

  1. Note which rule owns each side. Left side (x < −2): the quadratic. Right side (x ≥ −2): the line.
  2. Left-hand limit — plug −2 into the quadratic.
    (−2)² + 8(−2) + 15 = 4 − 16 + 15 = 3
    So limx→−2− f(x) = 3.
  3. Right-hand limit — plug −2 into the line.
    −2(−2) − 10 = 4 − 10 = −6
    So limx→−2+ f(x) = −6.
  4. Find f(−2). The ≥ belongs to the line, so f(−2) = −6.
  5. Compare and classify. 3 ≠ −6, so the two-sided limit does not exist. Both one-sided limits are finite numbers that simply disagree → jump.

AnswerJump discontinuity at x = −2.

3f(x) = −x − 1 if x ≤ −4; x + 7 if x > −4, at x = −4

Type: piecewise — test the split point

  1. Left-hand limit (rule for x ≤ −4): −(−4) − 1 = 4 − 1 = 3.
  2. Right-hand limit (rule for x > −4): (−4) + 7 = 3.
  3. The sides agree, so limx→−4 f(x) = 3. ✓
  4. Find f(−4). The ≤ gives it to the first rule: f(−4) = 3. ✓
  5. Compare. Limit = 3 = function value. All three conditions pass.

AnswerContinuous at x = −4.

4f(x) = x²4x − 16at x = 4 and x = 0

Type: rational — factor and check the denominator

  1. Factor the denominator. 4x − 16 = 4(x − 4), so the only bad value is x = 4.
  2. Can anything cancel? Numerator is x² = x·x. There is no (x − 4) upstairs — nothing cancels.
  3. Test x = 4. Denominator = 4(4) − 16 = 0 while numerator = 16 ≠ 0. Dividing a nonzero number by something shrinking to zero blows up, so the outputs run to ±∞.
    • from the left (x = 3.9): 15.2/(−0.4) → −∞
    • from the right (x = 4.1): 16.8/(0.4) → +∞
  4. Test x = 0. Denominator = −16 ≠ 0, so f(0) = 0/(−16) = 0. A rational function is continuous everywhere its denominator isn't zero.

AnswerInfinite discontinuity (vertical asymptote) at x = 4; continuous at x = 0.

5f(x) = x2 − 32 if x ≤ 0; −2x − 4 if x > 0, at x = 0

Type: piecewise — test the split point

  1. Left-hand limit (first rule): 02 − 32 = −32 = −1.5.
  2. Right-hand limit (second rule): −2(0) − 4 = −4.
  3. Find f(0). The ≤ gives it to the first rule: f(0) = −1.5.
  4. Compare and classify. −1.5 ≠ −4, two finite values that disagree → jump.

AnswerJump discontinuity at x = 0.

6f(x) = x − 5x² − 8x + 15at x = 3 and x = 5

Type: rational — factor, list bad values, then cancel

  1. Factor the denominator. Find two numbers that multiply to 15 and add to −8: that's −3 and −5.
    x² − 8x + 15 = (x − 3)(x − 5)
  2. List the bad values first. x = 3 and x = 5. Write these down before cancelling — both leave the domain permanently.
  3. Cancel. x − 5(x − 3)(x − 5) = 1x − 3, valid for x ≠ 5.
  4. Classify x = 5. Its factor cancelled, so the graph is a normal curve there with one point punched out → removable. Hole height: 1/(5 − 3) = ½, so the hole is at (5, ½).
  5. Classify x = 3. Its factor survived in the denominator → infinite discontinuity, vertical asymptote x = 3.

AnswerRemovable discontinuity at x = 5; infinite discontinuity at x = 3.

Continuity + domain · #7–10

Same routine as #6, with one extra line at the end: write the domain by cutting the number line at every bad x — holes included.

7f(x) = −x + 4x² + 9x + 20
  1. Factor the denominator. Two numbers multiplying to 20, adding to 9: 4 and 5.
    x² + 9x + 20 = (x + 4)(x + 5)
  2. Bad values. x + 4 = 0 → x = −4; x + 5 = 0 → x = −5.
  3. Cancel. −x + 4(x + 4)(x + 5) = −1x + 5, for x ≠ −4.
  4. Classify each. x = −4 cancelled → removable (hole at height −1/(−4 + 5) = −1). x = −5 survived → infinite.
  5. Write the domain. Cut the number line at −5 and −4, smallest first.

AnswerRemovable at x = −4, infinite at x = −5.
Domain: (−∞, −5) ∪ (−5, −4) ∪ (−4, ∞)

8f(x) = 2x − 4 if x < 3; −x2 − 32 if x ≥ 3
  1. Find the only suspect. Both pieces are lines (continuous on their own), so the only place a break can happen is the split, x = 3.
  2. Left-hand limit. 2(3) − 4 = 2.
  3. Right-hand limit. −32 − 32 = −3.
  4. Compare. 2 ≠ −3 → jump discontinuity at x = 3.
  5. Domain. Ask a different question here: is every real number assigned exactly one output? Yes — x < 3 uses the first rule, x ≥ 3 the second, and together they cover the whole line. A jump costs continuity, not domain.

AnswerJump discontinuity at x = 3. Domain: (−∞, ∞)

9f(x) = −x − 1x² + 2x + 2
  1. Try to factor the denominator. You need two numbers multiplying to 2 and adding to 2 — there aren't any whole numbers that work.
  2. Use the discriminant to prove it never equals zero.
    b² − 4ac = (2)² − 4(1)(2) = 4 − 8 = −4
    Negative discriminant → no real solutions to x² + 2x + 2 = 0.
  3. Conclude. The denominator is never zero, so there are no suspects at all.
  4. Domain. Nothing is excluded.

AnswerContinuous for all real numbers — no discontinuities. Domain: (−∞, ∞)

Alternate proof: complete the square. x² + 2x + 2 = (x + 1)² + 1, which is at least 1 — always positive.

10f(x) = x − 2x² − 6x + 5
  1. Factor. Two numbers multiplying to 5, adding to −6: −1 and −5 → (x − 1)(x − 5).
  2. Bad values. x = 1 and x = 5.
  3. Check for cancelling. The numerator is x − 2 — it matches neither factor, so nothing cancels.
  4. Classify. Both factors stay in the denominator → both are infinite discontinuities (vertical asymptotes at x = 1 and x = 5).
  5. Domain. Cut at 1 and at 5.

AnswerInfinite discontinuities at x = 1 and x = 5.
Domain: (−∞, 1) ∪ (1, 5) ∪ (5, ∞)

End behavior, no calculator · #11–14

For a polynomial, only the leading term survives at the extremes. For a rational function, compare the top and bottom degrees.

11f(x) = x⁵ − 4x³ + x + 1
  1. Find the leading term. Highest power is x⁵, with coefficient +1.
  2. Degree: even or odd? 5 is odd → the two ends go opposite directions.
  3. Sign of the lead? Positive → the right end goes up.
  4. Sanity-check with a big number. At x = −100, x⁵ = −10,000,000,000 while −4x³ = +4,000,000 — the leading term swamps everything, so the output is hugely negative.

Answerx → −∞: f(x) → −∞  ·  x → ∞: f(x) → ∞

12f(x) = −x⁴ − 4x³ − 3x² + 1
  1. Leading term: −x⁴.
  2. Degree 4 is even → both ends go the same direction.
  3. Coefficient is negative → that shared direction is down. (A plain x⁴ opens up; the minus sign flips it.)
  4. Check: at x = ±10, −x⁴ = −10,000 either way.

Answerx → −∞: f(x) → −∞  ·  x → ∞: f(x) → −∞

13m(x) = 4 + x2x + 6
  1. Put both parts in standard order. x + 42x + 6.
  2. Compare degrees. Top is degree 1, bottom is degree 1 — equal.
  3. Equal degrees → ratio of leading coefficients. Top lead 1, bottom lead 2, so the limit is ½.
  4. Show why (divide every term by x):
    x + 42x + 6 = 1 + 4/x2 + 6/x → as x grows, 4/x and 6/x vanish, leaving 12. The same thing happens at −∞.

Answerlimx→−∞ m(x) = ½  ·  limx→∞ m(x) = ½  (horizontal asymptote y = ½)

14k(x) = 4x² + 3x − 12x⁵ + 3x²
  1. Degrees: top is 2, bottom is 5.
  2. Bottom-heavy (denominator degree is larger) → limit 0.
  3. Why: divide top and bottom by x⁵:
    4/x³ + 3/x⁴ − 1/x⁵2 + 3/x³ → the whole numerator goes to 0 while the denominator goes to 2, so the fraction goes to 0/2 = 0.

Answerlimx→−∞ k(x) = 0  ·  limx→∞ k(x) = 0

End behavior in limit notation · #17–20

Each of these has a graph printed next to it — do the algebra first, then confirm it against the picture.

17f(x) = x² − 163x − 9
  1. Degrees: top 2, bottom 1 → top-heavy.
  2. Top-heavy means no horizontal asymptote — the outputs run to infinity instead of settling.
  3. Divide the leading terms to see which way. x²3x = x3 — it behaves like a line with positive slope far out.
  4. Read off both ends. A positive-slope line goes down on the left, up on the right — which matches the two arms on the printed graph.

Answerlimx→−∞ f(x) = −∞  ·  limx→∞ f(x) = ∞

18f(x) = −3x² + 12xx² − 2x − 3
  1. Degrees: 2 and 2 — equal.
  2. Take the ratio of the leading coefficients only. −3 ÷ 1 = −3. The 12x and the −2x − 3 play no part.
  3. Both ends get the same value when degrees are equal.
  4. Confirm on the graph: that's the dashed horizontal line at y = −3 the curve flattens onto at the far left and far right.

Answerlimx→−∞ f(x) = −3  ·  limx→∞ f(x) = −3

19f(x) = −4x² − x − 6
  1. Degrees: the numerator −4 is a constant (degree 0); the denominator is degree 2.
  2. Bottom-heavy → limit 0 at both ends.
  3. Why: at x = 1000 the denominator is about a million, and −4 divided by a million is essentially zero.
  4. Graph check: both arms flatten onto the x-axis, which is the horizontal asymptote y = 0.

Answerlimx→−∞ f(x) = 0  ·  limx→∞ f(x) = 0

20Read the end behavior from the graph
  1. Left arm. Put your finger on the curve and slide left. It flattens out and hugs a horizontal line at height −5, getting closer but never leaving it.
  2. That flattening is a limit — the height it hugs is the answer for x → −∞.
  3. Right arm. Slide right instead: the curve climbs steeply and never levels off, so it grows without bound.

Answerlimx→−∞ f(x) = −5  ·  limx→∞ f(x) = ∞

Locating zeros with the IVT · #21–22

Both are polynomials, so both are continuous — say so, because that's what licenses the theorem. Then hunt for a sign change between consecutive integers.

21f(x) = x² − 5x + 3on 0 ≤ x ≤ 6
  1. State why the IVT applies. f is a polynomial, so it is continuous on [0, 6].
  2. Evaluate at every integer in the range. Show the arithmetic:
    • f(0) = 0 − 0 + 3 = 3
    • f(1) = 1 − 5 + 3 = −1
    • f(2) = 4 − 10 + 3 = −3
    • f(3) = 9 − 15 + 3 = −3
    • f(4) = 16 − 20 + 3 = −1
    • f(5) = 25 − 25 + 3 = 3
    • f(6) = 36 − 30 + 3 = 9
  3. Put it in a table and add a sign row.
    x0123456
    f(x)3−1−3−3−139
    sign+−−−−++
  4. Find every place the sign flips. + → − between x = 0 and x = 1; − → + between x = 4 and x = 5.
  5. Write the conclusion in IVT language. Since f is continuous and changes sign, it must equal 0 somewhere inside each of those intervals.

AnswerA zero between x = 0 and x = 1, and another between x = 4 and x = 5.

22f(x) = 2x³ + 15x² − 4x − 33
  1. State continuity. Polynomial → continuous everywhere, so the IVT applies on any interval.
  2. Decide how many zeros to look for. Degree 3 → at most 3 real zeros. Once you've bracketed three, stop.
  3. Start sampling integers near zero and work outward. A sample of the arithmetic:
    • f(1) = 2 + 15 − 4 − 33 = −20
    • f(2) = 2(8) + 15(4) − 8 − 33 = 16 + 60 − 41 = 35
    • f(−1) = −2 + 15 + 4 − 33 = −16
    • f(−2) = 2(−8) + 15(4) + 8 − 33 = −16 + 60 − 25 = 19
    • f(−7) = 2(−343) + 15(49) + 28 − 33 = −686 + 735 − 5 = 44
    • f(−8) = 2(−512) + 15(64) + 32 − 33 = −1024 + 960 − 1 = −65
  4. Lay out the table.
    x−8−7−2−1012
    f(x)−654419−16−33−2035
    sign−++−−−+
  5. Collect the sign changes. Three of them — and a cubic can't have more, so the search is complete.

AnswerZeros between x = −8 and x = −7, between x = −2 and x = −1, and between x = 1 and x = 2.

Note the outputs stay negative from −1 through 1 — no sign change there, so no zero is claimed in that stretch.

Continuity, end behavior, and zeros · #1–3

Three questions per function, all answered by one factorization: leftover denominator factors give asymptotes, cancelled factors give holes, leftover numerator factors give zeros, and the degrees give end behavior.

1g(x) = 2x − 1x² − 4x − 32
  1. Factor the denominator. Two numbers multiplying to −32, adding to −4: −8 and +4.
    x² − 4x − 32 = (x − 8)(x + 4)
  2. Bad values: x = 8 and x = −4.
  3. Check for cancelling. The numerator 2x − 1 matches neither factor → nothing cancels → both are vertical asymptotes.
  4. Describe continuity. Continuous everywhere except those two points; write the domain by cutting at −4 and 8.
  5. End behavior: degree 1 over degree 2 → bottom-heavy → both limits are 0, horizontal asymptote y = 0.
  6. Zeros: set the numerator equal to zero. 2x − 1 = 0 → x = ½, and ½ is in the domain, so it counts.

Answer Continuity: infinite discontinuities at x = −4 and x = 8; domain (−∞, −4) ∪ (−4, 8) ∪ (8, ∞)
End behavior: limx→±∞ g(x) = 0
Zero: x = ½

2h(x) = x³ − 3x² + 2x − 6x² + 2x − 15
  1. Factor the numerator by grouping (four terms → group in pairs):
    (x³ − 3x²) + (2x − 6) = x²(x − 3) + 2(x − 3) = (x − 3)(x² + 2)
  2. Factor the denominator. Two numbers multiplying to −15, adding to 2: 5 and −3 → (x + 5)(x − 3).
  3. Bad values: x = −5 and x = 3.
  4. Cancel. h(x) = (x − 3)(x² + 2)(x + 5)(x − 3) = x² + 2x + 5, for x ≠ 3.
  5. Classify. x = 3 cancelled → hole; its height is the reduced form at 3: (9 + 2)/(3 + 5) = 118. x = −5 survived → vertical asymptote.
  6. End behavior. Original degrees: 3 over 2 → top-heavy, so no horizontal asymptote. Divide the leading terms: x³/x² = x, which behaves like a positive-slope line → down on the left, up on the right.
  7. Zeros. Set the surviving numerator to zero: x² + 2 = 0 → x² = −2, which has no real solution.

Answer Continuity: hole at (3, 11/8), infinite discontinuity at x = −5; domain (−∞, −5) ∪ (−5, 3) ∪ (3, ∞)
End behavior: x → −∞: h(x) → −∞; x → ∞: h(x) → ∞
Zeros: none (no real zeros)

Extra credit detail: long division gives x² + 2x + 5 = x − 5 + 27x + 5, so the graph rides the slant asymptote y = x − 5 at the ends.

3f(x) = x² + 5x − 142x² + x − 10
  1. Factor the numerator. Multiply to −14, add to 5: 7 and −2 → (x + 7)(x − 2).
  2. Factor the denominator (leading coefficient isn't 1, so use the AC method). a·c = 2(−10) = −20; need two numbers multiplying to −20 and adding to 1: 5 and −4.
    2x² + 5x − 4x − 10 = x(2x + 5) − 2(2x + 5) = (2x + 5)(x − 2)
  3. Bad values: 2x + 5 = 0 → x = −52, and x = 2.
  4. Cancel. f(x) = x + 72x + 5, for x ≠ 2.
  5. Classify. x = 2 cancelled → hole at height (2 + 7)/(2(2) + 5) = 9/9 = 1, so the hole is (2, 1). x = −5/2 survived → vertical asymptote.
  6. End behavior. Degrees 2 and 2 — equal → ratio of leading coefficients 1/2, both ends.
  7. Zeros. x + 7 = 0 → x = −7. It's in the domain, so it's a genuine zero. Note x = 2 is not a zero — it's the hole.

Answer Continuity: hole at (2, 1), infinite discontinuity at x = −5/2; domain (−∞, −5/2) ∪ (−5/2, 2) ∪ (2, ∞)
End behavior: limx→±∞ f(x) = ½ (horizontal asymptote y = ½)
Zero: x = −7

Solving for parameters & the function test · #4–5

4Find a and b so that f is continuous

f(x) = x² + a for x ≥ 3; bx + a for −3 < x < 3; √−b − x for x ≤ −3

  1. Find the places that could break. Each piece is continuous on its own, so the only suspects are the two boundaries: x = 3 and x = −3. Continuity means the pieces must meet at both.
  2. Set up the equation at x = 3. Middle piece approaching from the left vs. the top piece owning the right:
    b(3) + a = (3)² + a
  3. Solve it. The a appears on both sides and cancels:
    3b + a = 9 + a → 3b = 9 → b = 3
    Do this equation first — it's the one that collapses to a single variable.
  4. Set up the equation at x = −3. The radical piece owns x = −3; the middle piece approaches from the right:
    √−b − (−3) = b(−3) + a, i.e. √3 − b = −3b + a
  5. Substitute b = 3. Left side: √3 − 3 = √0 = 0. Right side: −9 + a.
    −9 + a = 0 → a = 9
  6. Check both boundaries. At x = 3: 9 + 9 = 18 and 3(3) + 9 = 18. ✓ At x = −3: √0 = 0 and 3(−3) + 9 = 0. ✓
  7. Check the radical is even legal. −b − x ≥ 0 → −3 − x ≥ 0 → x ≤ −3 — exactly the interval that piece is defined on. Everything is consistent.

Answera = 9, b = 3

5Explain why the relation is not a function

y = 2x for x ≤ 1; y = 3 for x ≥ 1

  1. Look at the inequality signs, not the formulas. The first says x ≤ 1; the second says x ≥ 1. Both include x = 1.
  2. Evaluate at the overlap. First rule: y = 2(1) = 2. Second rule: y = 3.
  3. Apply the definition. A function assigns each input exactly one output. The input x = 1 has two, so this fails.
  4. Say it graphically too. The vertical line x = 1 hits the graph at (1, 2) and (1, 3) — it fails the vertical line test.

AnswerAt x = 1 both rules apply, giving y = 2 and y = 3. One input with two outputs is not a function. (Changing the second condition to x > 1 would fix it.)
