Evaluating and building functions · #9–16

The whole idea in #9–12: the input is a placeholder. Wherever you see x in the rule, drop the new input in — parentheses included — then simplify. −f(x) is different: evaluate first, then negate the whole output.

9f(x) = 2x² + 3x − 5

Answers A. f(−1) = −6
B. −f(x) = −2x² − 3x + 5
C. f(2x) = 8x² + 6x − 5

  • A: 2(−1)² + 3(−1) − 5 = 2 − 3 − 5
  • B: distribute the negative to all three terms.
  • C: 2(2x)² = 2·4x² = 8x² — the square hits the 2 as well.

10f(x) = |x| − 3

Answers A. f(−x) = |x| − 3
B. f(x − 1) = |x − 1| − 3
C. f(3x) = 3|x| − 3

  • A: |−x| = |x|, so nothing changes — this function is even.
  • B: keep the whole binomial inside the bars.
  • C: |3x| = |3|·|x| = 3|x|; a positive factor comes out.

11f(x) = √x² − x

Answers A. f(−1) = √2
B. f(−x) = √x² + x
C. −f(x) = −√x² − x

  • A: (−1)² − (−1) = 1 + 1 = 2.
  • B: (−x)² = x² but −(−x) = +x. Only the linear term flips.
  • C: the negative sits outside the radical — you are not allowed to move it in.

12f(x) = xx² − 1

Answers A. −f(x) = −xx² − 1
B. f(x + 1) = x + 1x² + 2x = x + 1x(x + 2)
C. f(x + h) = x + h(x + h)² − 1

  • B: (x + 1)² − 1 = x² + 2x + 1 − 1 = x² + 2x. Expanding is what makes the “−1” cancel.
  • C: leave it unexpanded unless the problem asks for a difference quotient.

13Find A if f(2) = 13

f(x) = 2x³ + Ax² + 4x − 3

AnswerA = −2

Substitute x = 2 and set the result equal to 13:
2(8) + A(4) + 8 − 3 = 13 → 4A + 21 = 13 → 4A = −8.

14Find B if f(−2) = 52

f(x) = 2x − B3x + 4

AnswerB = 1

−4 − B−2 = 52. Cross-multiply: 2(−4 − B) = −10, so −4 − B = −5 and B = 1. Check: (−5)/(−2) = 5/2. ✓

15Area of a square as a function of perimeter

AnswerA(P) = P²16

Link the two through the side length: P = 4s so s = P/4. Then A = s² = (P/4)². The side length is the bridge — write it, then eliminate it.

16Gross salary at $18/hour

AnswerS(h) = 18h

Rate × hours. Reasonable domain: h ≥ 0.

Change in Tandem · reading the graph of g · #17–21

Read the four labeled points as two different kinds of landmark. (−1.2, 1.5) and (2.6, −8.6) are turning points — where the graph switches between increasing and decreasing. (−2.2, 0.7) and (1.2, −4.3) are points of inflection — the graph keeps going the same direction there, but the bend flips.

The shape, in words: falls from the upper left to a low point at x ≈ −3 (it just touches the x-axis) · rises through (−2.2, 0.7) to the local max (−1.2, 1.5) · falls through (1.2, −4.3) to the local min (2.6, −8.6) · then rises steeply off the top of the window.

17Is g increasing or decreasing at x = 1?

AnswerDecreasing.

x = 1 sits between the local max at x = −1.2 and the local min at x = 2.6. On that whole stretch, as the input increases the output falls — e.g. the graph drops from 1.5 down past −4.3 at x = 1.2.

18Is the rate of change increasing or decreasing at x = 1?

AnswerDecreasing (the slopes are getting more negative).

At x = 1 the graph is concave down — it lies below its tangent line, and the inflection point isn’t reached until x = 1.2. Concave down means the slope values are decreasing, so the function is falling faster and faster there. Careful: “decreasing function” (#17) and “decreasing rate of change” (#18) are separate questions — here they happen to agree.

19Where is g concave up?

Answer(−∞, −2.2) ∪ (1.2, ∞) — on the picture, roughly (−3.6, −2.2) ∪ (1.2, 4.3).

Concave up = cupped upward, holding water, slopes increasing. That’s the valley on the far left and the whole valley containing (2.6, −8.6). The endpoints are the two inflection points — always give concavity in open intervals of x.

20Where is g concave down?

Answer(−2.2, 1.2)

The arch containing the local max at (−1.2, 1.5). It runs from one inflection point to the next.

21Where does g change from decreasing to increasing?

Answerx ≈ −3 and x = 2.6

Those are the two local minimums — the bottom of a valley is exactly where falling turns into rising. (The one at x ≈ −3 isn’t labeled with a coordinate; read it off the axis where the curve dips to touch it.) The local max at x = −1.2 is the reverse change, so it doesn’t belong here.

Behavior, inflection points, concavity · #22–26

Two rules that decide most of these: intervals of increasing/decreasing/constant are always given in x-values and always open; a point of inflection is where concavity changes, not where direction changes.

22Reading y = F(x)

Landmarks on the picture: a sharp low point at (−8, −3), a smooth peak at (−3, 5), a sharp low point at (2, −3), then a straight climb that levels off at (8, 3) and stays there.

Answers A. increasing on (−8, −3) ∪ (2, 8)
B. decreasing on (−∞, −8) ∪ (−3, 2)
C. constant on (8, ∞)
D. x-intercepts ≈ −7, 1.5, 5  ·  y-intercept ≈ 2.5
E. relative max 5 at x = −3 · relative min −3 at x = −8 and x = 2; −3 is the absolute min, and there is no absolute max

  • Direction changes happen at the turning points x = −8, −3, 2; the flat part starts at x = 8.
  • No absolute maximum: the arrow on the left keeps rising without bound, so no output is ever the largest.
  • The last piece is a line through (2, −3) and (8, 3) — slope 1 — so its zero is exactly x = 5.

23How many inflection points?

AnswersA. 2  ·  B. 3

Count the turning points first, then mark one inflection between each consecutive pair — the curve has to change its bend to get from a hilltop to a valley floor.

  • A has three turning points (small hill → shallow dip → tall peak), so mark inflections in two places: on the drop between the small hill and the dip, and on the steep rise just before the tall peak (near the origin). After the tall peak it stays concave down all the way to the arrow.
  • B has four turning points (peak → deep valley → small peak → small valley), so mark three inflections: one between each neighboring pair.

Answer(−2, 0), (2, −1), and (5, 0.5)

These are exactly the labeled points that sit between two turning points. The turning points themselves — (−4, 5), (−0.5, −5), (4, 2), (6, −1) — are maxima and minima, and (−6, −4), (8, 4) are just points on the steep end pieces. An inflection point needs both coordinates in your answer.

Answers 25. concave up on (−2, 2) ∪ (5, ∞)
26. concave down on (−∞, −2) ∪ (2, 5)

Start at the far left and flip the answer at each inflection x-value from #24 — −2, then 2, then 5. Turn each sentence into a time interval and a starting/ending height, then connect them in order. The clock never resets: each phase begins where the last one ended.

28Car: 45 mph → 60 mph, cruise, then stop

Accelerates 45→60 mph over the first 8 s · holds 60 mph for 5 s · slows to a stop over the next 7 s. The y-axis is speed, not distance.

Answers B. domain [0, 20] seconds · range [0, 60] mph
C. v = 60 for 8 ≤ t ≤ 13

C is a horizontal line: the speed doesn’t change over that interval, so the slope is 0 and the equation is just y = 60. Range starts at 0 because the car really does reach a stop; it never exceeds 60.

29Ethan’s distance from home

Walks 2 blocks in 4 min · runs home in 3 min · hunts for lunch 2 min · walks 5 blocks to school in 12 min · talks to Matt 4 min. The y-axis is distance from home, so going home means coming back down to 0.

Continuity, end behavior, IVT · #1–22

The answer key is printed on page 20 of your packet, so what follows is the work behind it. Continuity test at x = c: the left piece and the right piece must approach the same value, and f(c) must equal it. For rational functions, factor first — a factor that cancels is a hole (removable), a factor that survives in the denominator is a vertical asymptote (infinite).

1f(x) = x³ − 4x² + 3 at x = 4

AnswerContinuous at x = 4

Polynomials are continuous everywhere — no denominators, no radicals, no pieces. f(4) = 64 − 64 + 3 = 3.

2Piecewise at x = −2

AnswerJump discontinuity at x = −2

From the left: (−2)² + 8(−2) + 15 = 4 − 16 + 15 = 3.
From the right: −2(−2) − 10 = −6. Two different heights ⇒ jump.

3Piecewise at x = −4

AnswerContinuous at x = −4

Left: −(−4) − 1 = 3. Right: −4 + 7 = 3. They match, and the rule with the ≤ assigns f(−4) = 3.

4f(x) = x²4x − 16 at x = 4 and x = 0

AnswerInfinite discontinuity at x = 4; continuous at x = 0

4x − 16 = 4(x − 4) is zero at x = 4 while the numerator is 16 ≠ 0 — nothing cancels, so it’s a vertical asymptote. At x = 0 the denominator is −16, so f(0) = 0 exists.

5Piecewise at x = 0

AnswerJump discontinuity at x = 0

Left: 0/2 − 3/2 = −1.5. Right: −2(0) − 4 = −4.

6f(x) = x − 5x² − 8x + 15

AnswerRemovable at x = 5 · infinite at x = 3

Factor: x − 5(x − 3)(x − 5) = 1x − 3, x ≠ 5. The cancelled factor leaves a hole at x = 5 (height ½); x − 3 stays downstairs, so it’s an asymptote.

7f(x) = −x + 4x² + 9x + 20

AnswerRemovable at x = −4 · infinite at x = −5
Domain: (−∞, −5) ∪ (−5, −4) ∪ (−4, ∞)

x² + 9x + 20 = (x + 4)(x + 5), so the function reduces to −1/(x + 5) with a hole at x = −4. Both bad x-values still leave the domain, hole included.

8Piecewise, split at x = 3

AnswerJump discontinuity at x = 3 · domain (−∞, ∞)

Left: 2(3) − 4 = 2. Right: −3/2 − 3/2 = −3. Both pieces are lines, so every real number still gets exactly one output — a jump costs you continuity, not domain.

9f(x) = −x − 1x² + 2x + 2

AnswerContinuous everywhere · domain (−∞, ∞)

Discriminant of the denominator: 2² − 4(1)(2) = −4 < 0, so it never equals zero. No real x is excluded.

10f(x) = x − 2x² − 6x + 5

AnswerInfinite discontinuities at x = 1 and x = 5
Domain: (−∞, 1) ∪ (1, 5) ∪ (5, ∞)

(x − 1)(x − 5) in the denominator, nothing cancels with x − 2.

End behavior (#11–14, 17–20). For a polynomial, only the leading term matters: even degree sends both ends the same way, odd degree sends them opposite ways, and a negative leading coefficient flips both. For a rational function compare degrees — bottom-heavy → limit 0; equal degrees → ratio of leading coefficients; top-heavy → ±∞.

11f(x) = x⁵ − 4x³ + x + 1

Answerx → −∞: f(x) → −∞
x → ∞: f(x) → ∞

Odd degree, positive lead — down on the left, up on the right.

12f(x) = −x⁴ − 4x³ − 3x² + 1

AnswerBoth ends → −∞

Even degree keeps the ends together; the negative lead points them both down.

13m(x) = 4 + x2x + 6

AnswerBoth ends → ½  (horizontal asymptote y = ½)

Equal degrees (both 1), so take 1/2 from the leading coefficients.

14k(x) = 4x² + 3x − 12x⁵ + 3x²

AnswerBoth ends → 0

Degree 2 over degree 5 — the denominator grows far faster, so the fraction is squeezed to zero.

17f(x) = x² − 163x − 9

Answerlimx→−∞ f(x) = −∞  ·  limx→∞ f(x) = ∞

Top-heavy by one degree, so it behaves like the line x/3 far out — matching the graph’s arms.

18f(x) = −3x² + 12xx² − 2x − 3

AnswerBoth limits = −3

Equal degrees: −3/1. That’s the dashed horizontal asymptote at y = −3 in the picture, which the graph approaches from both directions.

19f(x) = −4x² − x − 6

AnswerBoth limits = 0

Constant over quadratic. The graph flattens onto y = 0 at both ends.

Answerlimx→−∞ f(x) = −5  ·  limx→∞ f(x) = ∞

The left arm levels off along the horizontal line y = −5; the right arm climbs without bound.

Continuity, end behavior, and zeros · #1–5

Same three questions each time. Factor top and bottom first — the factorization answers all three at once: leftover denominator factors give asymptotes, cancelled factors give holes, and leftover numerator factors give zeros.

1g(x) = 2x − 1x² − 4x − 32

Factored: 2x − 1(x − 8)(x + 4) — nothing cancels.

Answers Continuity: continuous on its domain (−∞, −4) ∪ (−4, 8) ∪ (8, ∞); infinite discontinuities (vertical asymptotes) at x = −4 and x = 8.
End behavior: both limits = 0, horizontal asymptote y = 0.
Zero: x = ½

Degree 1 over degree 2 is bottom-heavy, so the ends flatten to zero. A rational function is zero exactly where its numerator is: 2x − 1 = 0.

2h(x) = x³ − 3x² + 2x − 6x² + 2x − 15

Factored: group the top — x²(x − 3) + 2(x − 3) = (x − 3)(x² + 2); bottom is (x + 5)(x − 3). So h(x) = x² + 2x + 5 with x ≠ 3.

Answers Continuity: removable discontinuity (hole) at x = 3, at height 11/8; infinite discontinuity at x = −5. Domain (−∞, −5) ∪ (−5, 3) ∪ (3, ∞).
End behavior: x → −∞: h(x) → −∞; x → ∞: h(x) → ∞ (top-heavy by one degree — there’s a slant asymptote, no horizontal one).
Zeros: none — x² + 2 = 0 has no real solution.

Grouping is the move whenever a cubic has four terms. Hole height comes from the reduced form at x = 3: (9 + 2)/(3 + 5) = 11/8.

3f(x) = x² + 5x − 142x² + x − 10

Factored: (x + 7)(x − 2)(2x + 5)(x − 2) = x + 72x + 5, x ≠ 2.

Answers Continuity: hole at x = 2 (height 1); vertical asymptote at x = −5/2. Domain (−∞, −5/2) ∪ (−5/2, 2) ∪ (2, ∞).
End behavior: both limits = ½, horizontal asymptote y = ½.
Zero: x = −7

Note what the cancelled factor costs you: x = 2 is not a zero even though x − 2 was in the numerator — it’s a hole, and the function has no value there at all. Hole height: (2 + 7)/(4 + 5) = 1.

4Find a and b so f is continuous

f(x) = x² + a for x ≥ 3; bx + a for −3 < x < 3; √−b − x for x ≤ −3.

Answera = 9, b = 3

  • Match at x = 3: 3² + a = 3b + a → the a’s cancel → 9 = 3b → b = 3.
  • Match at x = −3: √−b + 3 = −3b + a. With b = 3 the radical is √0 = 0, so −9 + a = 0 → a = 9.
  • Check: at x = 3 both give 18; at x = −3 both give 0. ✓

Do the x = 3 equation first — it’s the one where a variable cancels, which turns a two-unknown system into a single step.

5Why isn’t this relation a function?

y = 2x for x ≤ 1, and y = 3 for x ≥ 1.

AnswerBecause x = 1 satisfies both conditions, it produces two outputs: y = 2(1) = 2 and y = 3. One input, two outputs — that fails the definition of a function (and the vertical line test at x = 1).

Look at the inequality symbols, not the formulas. Both pieces use a closed endpoint at 1; the fix would be making one of them strict, e.g. x > 1.
